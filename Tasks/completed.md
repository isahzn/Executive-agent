## Using Completion History

### Referencing Past Work
If similar work comes up:
1. Search completed.md for related tasks.
2. Check the outcome and lessons.
3. Apply lessons to avoid repeating mistakes.
4. Use approach if it worked well before.

### Learning from Completion
When a task completes:
1. Record the outcome (success/failure/partial).
2. Record lessons in Memory/lessons.md if applicable.
3. Record decisions in Memory/decisions.md if applicable.
4. Update activity log in Memory/activity.log.

### Spotting Patterns
If similar tasks complete repeatedly:
1. Document the pattern.
2. Create a reusable skill or process.
3. Add to Memory/lessons.md.
4. Standardize the approach.

## Archiving Completed Tasks

Completed tasks stay in this file indefinitely for reference.

If the file becomes very large (100+ tasks):
1. Archive old tasks to a historical file (e.g., completed-archive-2026.md).
2. Keep current year's completions in this file.
3. Link to archives from this file.

---

## Success vs. Failure

### Successful Completion
- Objective was achieved.
- Scope was honored.
- Quality requirements met.
- No unexpected issues.

### Partial Completion
- Some objectives achieved.
- Scope partially delivered.
- Remaining work moved to backlog or abandoned.

### Failed Completion
- Objective was not achieved.
- Work was abandoned or blocked.
- Document why it failed.
- Learn from the failure.

## Completion Checklist

Before moving a task to completed:
- [ ] All approved work is done
- [ ] Scope was honored (no expansion)
- [ ] Verification/review passed (or documented why not)
- [ ] Lessons are recorded (if applicable)
- [ ] Decisions are recorded (if applicable)
- [ ] Outcome is documented
- [ ] Related files are updated
- [ ] Completion date is recorded

---

## Rules for Task Completion

- **Do not mark complete until done**: A task is not complete if work remains.
- **Do record lessons**: If something was learned, record it.
- **Do not delete**: Archive, never delete completed tasks.
- **Do update memory**: If decisions or lessons emerged, update Memory files.
- **Do not carry over to next phase** without closure. Each phase should complete its tasks.
